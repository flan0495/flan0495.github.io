眠れる歴史の話 アップローダー／制定：2026年11月5日

このアプリについて

「眠れる歴史の話 アップローダー」は、YouTube チャンネル「眠れる歴史の話」の運営者が、自分のチャンネルに動画をアップロードするための道具です。使うのは運営者本人だけで、ほかの人の Google アカウントでは使いません。

使う権限

Google の「YouTube への動画のアップロード」の権限（https://www.googleapis.com/auth/youtube.upload）だけを使います。動画の削除、チャンネルの設定の変更、視聴履歴やメールなど、ほかのデータには触れません。

扱う情報

  • アップロードのための認証情報（OAuth のトークン）を、運営者が管理する作業環境にだけ保存します。
  • この情報を第三者に渡したり、販売したり、広告に使ったりすることはありません。
  • このアプリとこのウェブサイトは、訪問者の個人情報を集めず、アクセス解析も行いません。

Google API から受け取った情報の扱いは、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

許可の取り消し

このアプリへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

お問い合わせ

YouTube チャンネル「眠れる歴史の話」の概要欄から、お問い合わせください。

English summary: "眠れる歴史の話 アップローダー" is a personal tool used only by the owner of the YouTube channel "眠れる歴史の話" to upload videos to that channel. It requests only the YouTube upload scope (youtube.upload). OAuth tokens are stored only in the owner's own working environment and are never shared, sold or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/connections. This site collects no personal data and uses no analytics.
